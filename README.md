# Breast Cancer Mini Project

This project performs exploratory data analysis and preprocessing on the Wisconsin Breast Cancer dataset.

## Tasks Completed

- Read the dataset using Pandas
- Checked for missing values
- Removed missing value entries
- Dropped unnecessary columns such as `id`
- Encoded the diagnosis column
- Scaled numerical features
- Saved the preprocessed dataset as `data_refined.csv`
- Created pair plots for selected features
- Created a correlation matrix heatmap
- Created box plots for selected features
- Created violin plots for selected features
- Described what violin plots show
- Checked possible outliers using the visualizations
